This project explored classification of Sudoku and non-Sudoku images using three neural network architectures: Auto-Encoder (AE), Variational Auto-Encoder (VAE), and Convolutional Neural Network (CNN).

The experiments compared model performance on a dataset of 3x3 Sudoku and non-Sudoku images based on MNIST digits.
